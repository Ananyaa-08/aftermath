## Fraunces

- Asset: `apps/web/app/fonts/Fraunces.ttf`
- Typeface: Fraunces Roman variable font
- Creator: Undercase Type; project authors are identified in the bundled license and upstream repository
- Source: [official Fraunces project](https://github.com/undercasetype/Fraunces), downloaded through the official Google Fonts repository
- License: SIL Open Font License 1.1
- Local license: `apps/web/app/fonts/OFL.txt`
- Use: self-hosted through `next/font/local`; no browser request to a font CDN

No third-party photography, stock image, logo, icon set, or illustration is used. The homepage document collage and workspace SVG sculpture are original code-built decorative compositions. The two user-provided reference images informed layout and typographic direction only and are not shipped as site assets.
